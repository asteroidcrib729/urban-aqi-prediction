# Air Quality Prediction (PM2.5 Forecasting)

End-to-end exploratory data analysis, leak-free next-day (`t+1`) **PM2.5**
forecasting (`LinearRegression`), and an interactive 50-city air quality
dashboard unified in a single Jupyter notebook.

## Project Structure

- `urban-aqi-prediction.ipynb` - Unified end-to-end notebook covering:
  1. **Environment Setup & Data Loading** - Loads
     `dataset/air_quality_daily.csv`, parses dates (`%Y-%m-%d`), encodes
     `city_id` (`0-49`), and adds calendar features (`month`, `day_of_week`,
     `day_of_year`).
  2. **Exploratory Data Analysis & PACF** - Inspects pollutant/aerosol
     correlations with `pm2_5_mean`, India AQI category distributions, top
     polluted cities, and single-city partial autocorrelation (`Delhi`).
  3. **City-Grouped Feature Engineering & Model Training** - Builds leak-free
     `city_id`-grouped lag (`1, 2, 3` days) and rolling (`3, 7` days)
     features (`60` engineered features total), splits chronologically per city
     (`80/10/10`), trains `LinearRegression` for next-day `pm2_5_mean` (`t+1`),
     plots diagnostics, and saves
     `model/air_quality_linear_regression_model.pkl`.
  4. **Interactive City Dashboard (`ipywidgets` + `folium`)** - Displays
     next-day `PM2.5` forecast, 30-day actual vs. predicted chart, top-5
     correlations, and a 50-city Folium map (`Esri.WorldTopoMap`) exported to
     `visualizations/air_quality_map.html`.
- `dataset/`
  - `air_quality_daily.csv` - Unified daily air quality dataset (`78,500` rows
    x `19` columns, `2022-08-05` to `2026-11-21`, `50` cities, `0` missing
    values), sourced from
    [Hugging Face](https://huggingface.co/datasets/AkshayKarthick/india-weather-air-quality).
- `model/`
  - `air_quality_linear_regression_model.pkl` - Serialized `LinearRegression`
    artifact (`model`, `feature_columns`, `city_map`).
- `visualizations/`
  - `air_quality_map.html` - Interactive 50-city Folium map generated by
    Section 4 using keyless `Esri.WorldTopoMap` tiles for reliable local
    `file://` and browser rendering.
- `tests/`
  - `test_project.py` - Automated verification suite validating configs,
    notebook compilation/outputs, dataset invariants, serialized model metrics,
    and map tile/popup regressions.
- `.github/workflows/ci.yml` - GitHub Actions workflow running Ruff, Pyrefly,
  and `unittest` on Python `3.14`.

## Verified Metrics Snapshot

- **Dataset:** `78,500` rows x `19` columns (`50` cities, `2022-08-05` to
  `2026-11-21`, `0` missing values)
- **Engineered Features:** `60` leak-free city-grouped features
- **Chronological Splits:** Train `62,500` | Validation `7,800` | Test `7,850`
- **Validation (`t+1` PM2.5):** RMSE `11.19` | MAE `7.39` | R² `0.8420`
- **Test (`t+1` PM2.5):** RMSE `9.68` | MAE `6.31` | R² `0.8414`

## Python & IDE Configuration

This project targets the global Python `3.14.7` interpreter without requiring a
project-local `.venv`.

- `.python-version` - Pins Python `3.14.7`.
- `pyproject.toml` - Declares `requires-python = ">=3.14.7,<3.15"`, runtime
  dependencies, optional typing stubs (`pandas-stubs`, `types-seaborn`), MIT
  license metadata, and Ruff lint settings (`E4`, `E7`, `E9`, `F`, `I`).
- `requirements.txt` - Flexible version bounds (`>=installed,<next_major` for
  SemVer packages and `>=installed` for CalVer stubs).
- `pyrefly.toml` - Configures Pyrefly across `**/*.py*` and `**/*.ipynb` using
  Python `3.14` and the global/user `site-packages`.
- `.vscode/settings.json` & `.vscode/extensions.json` - Configures VS Code for
  system Python (`ms-python.python:system` + `pip`), bundled Pyrefly
  (`python.languageServer: "None"`, `python.pyrefly.syncNotebooks: true`),
  Ruff, Jupyter kernel filtering (`jupyter.excludeUserSitePackages: false`), and
  recommended extensions (`python`, `vscode-python-envs`, `pyrefly`, `jupyter`,
  `ruff`, `markdownlint`).

## First-Time Run Checklist

1. Verify Python `3.14.7` is active:

   ```bash
   python --version
   ```

2. Install runtime and typing dependencies into the global Python environment:

   ```bash
   pip install -r requirements.txt
   ```

3. Run static checks and automated verification tests:

   ```bash
   pyrefly check
   python -m unittest discover -s tests -v
   ```

4. Open and run `urban-aqi-prediction.ipynb` in VS Code (select the Python
   `3.14.7` kernel) or via standalone Jupyter:

   ```bash
   pip install notebook
   jupyter notebook urban-aqi-prediction.ipynb
   ```

## Troubleshooting

- **Missing packages in Jupyter kernel:** Confirm VS Code selects the Python
  `3.14.7` interpreter configured in `.vscode/settings.json` and that
  `jupyter.excludeUserSitePackages` remains `false`.
- **Map tiles failing locally:** `visualizations/air_quality_map.html` uses
  `Esri.WorldTopoMap` instead of OpenStreetMap/CARTO so tiles load cleanly
  over `file://` without `Referer` errors or API-key watermarks.
- **Pyrefly cannot find third-party packages:** Ensure `pyrefly.toml`
  `python-interpreter-path` and `site-package-path` match your local Python
  `3.14` installation paths (or pass `--python-interpreter-path` and
  `--site-packages-path` in CI).
